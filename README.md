# TaskFlow – Full-Stack Task Manager

TaskFlow is a full-stack task management application that helps users organise their daily activities, track progress and manage tasks easily.

## Live Demo

https://taskflow-frontend-yy1c.onrender.com

## Features

- User registration and login
- Secure password hashing
- JWT authentication
- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- User-specific task management
- PostgreSQL database integration

## Technologies Used

**Frontend**
- React
- Vite
- CSS
- Axios

**Backend**
- Node.js
- Express.js
- PostgreSQL
- JWT
- bcryptjs

**Deployment**
- GitHub
- Render

## Project Structure

- `client/` – React frontend
- `server/` – Express backend
- `server/db.js` – Database connection
- `server/auth.js` – Authentication middleware
- `server/server.js` – API routes and server

## Main Functionalities

1. Register a new account.
2. Log in securely.
3. Add tasks to your personal task list.
4. Mark tasks as completed or undo completion.
5. Delete tasks when they are no longer needed.
